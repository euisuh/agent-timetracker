# Agent Instructions

## Time tracking

This repository documents a self-hosted time-tracker (the original service is retired). Before calling it, read
`docs/MODEL_API.md` completely.

Follow the lifecycle in [`docs/MODEL_API.md`](docs/MODEL_API.md). Classify the
task with [`PROJECTS.md`](PROJECTS.md) and select an independent intended purpose
with [`docs/PURPOSES.md`](docs/PURPOSES.md) when known; use an existing configured API user and
never commit or print real tokens.
